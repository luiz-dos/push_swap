# 📦 push_swap

**Description**  
Sorts a stack of integers using only stack operations (push, swap, rotate, reverse), minimizing the total number of moves.

**🛠️ Technologies**  
- C language  
- Custom linked-list implementation  

**🎯 Key Learning Outcomes**  
- Algorithm design under strict operational constraints  
- Analysis and optimization of move sequences  
- Advanced pointer manipulation
